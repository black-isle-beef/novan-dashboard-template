# Novan Dashboard Template

Novan is an Angular dashboard template and reusable UI library. The repository contains a runnable demo application and a distributable package with the dashboard shell, standalone components, sidebar state service, and Sass styles.

## Requirements

- Node.js 20.19.0 or newer
- npm 10 or newer
- Angular 22 in the consuming application

The library uses Angular standalone components and requires `@angular/core` and `@angular/common` 22.x as peer dependencies.

## Repository layout

```text
src/                         Demo Angular application
projects/novan-dashboard-ui/ Reusable Angular library source
dist/novan-dashboard-ui/     Generated library output
```

## Run the demo application

Install dependencies and start the demo:

```bash
npm install
npm start
```

The development server is available at `http://localhost:4200/`.

## Build the application

```bash
npm run build
```

The demo application is emitted to `dist/novan-dashboard-template/`.

## Build the npm package

Build the Angular library:

```bash
npm run build:library
```

The compiled package is emitted to `dist/novan-dashboard-ui/`. It contains:

- `NovanDashboardComponent`, the complete dashboard shell
- `NovanHeaderComponent`, with a configurable title
- `NovanSidebarComponent`, with collapsible state and cookie persistence
- `NovanFooterComponent`, with configurable footer text
- `UiStateService`, for sidebar state control
- Compiled declarations and Angular partial-Ivy output
- The reusable Sass style tree under `styles/`

Build both the demo and library together:

```bash
npm run build:all
```

Create an installable local tarball:

```bash
npm run pack:library
```

The tarball is written to `dist/` and can be installed into another project with its path.

## Install into another Angular project

### From a published registry package

After publishing the package under the chosen registry scope, install it with:

```bash
npm install @novan/dashboard-ui bootstrap bootstrap-icons
```

The consuming project must already have Angular 22 installed.

### From the local build tarball

Build and pack the library in this repository, then install the generated tarball from the consuming project:

```bash
npm install ../novan-dashboard-template/dist/novan-dashboard-ui-0.1.0.tgz
```

Use the actual tarball filename generated by `npm run pack:library` if the package version has changed.

## Configure styles

Add the package Sass entry point to the consuming application's `angular.json` build options:

```json
{
  "styles": [
    "node_modules/@novan/dashboard-ui/styles/styles.scss"
  ],
  "scripts": [
    "node_modules/bootstrap/dist/js/bootstrap.bundle.min.js"
  ]
}
```

The package stylesheet expects `bootstrap` and `bootstrap-icons` to be installed in the consuming project. Restart the Angular development server after changing `angular.json`.

The source style tree is also available for projects that prefer Sass composition:

```scss
@use '@novan/dashboard-ui/styles/styles';
```

## Use the complete dashboard

Import the standalone component into the consuming standalone component:

```typescript
import { Component } from '@angular/core';
import { NovanDashboardComponent } from '@novan/dashboard-ui';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [NovanDashboardComponent],
  template: '<novan-dashboard />',
})
export class AppComponent {}
```

The complete shell includes the header, collapsible sidebar, content area, cards, and footer. The sidebar state is persisted in the `sidebar-open` cookie.

## Use individual components

Each component can be imported independently for custom layouts:

```typescript
import { Component } from '@angular/core';
import {
  NovanFooterComponent,
  NovanHeaderComponent,
  NovanSidebarComponent,
} from '@novan/dashboard-ui';

@Component({
  selector: 'app-layout',
  standalone: true,
  imports: [NovanHeaderComponent, NovanSidebarComponent, NovanFooterComponent],
  template: `
    <novan-header title="Lorem ipsum dolor sit amet" />
    <novan-sidebar />
    <novan-footer text="Lorem ipsum dolor sit amet." />
  `,
})
export class LayoutComponent {}
```

### Component API

| Export | Inputs and behavior |
| --- | --- |
| `NovanDashboardComponent` | Complete ready-to-use dashboard shell. |
| `NovanHeaderComponent` | `title`: signal input for the page title. |
| `NovanSidebarComponent` | Uses `UiStateService`; the toggle updates `isSidebarOpen` and persists a cookie. |
| `NovanFooterComponent` | `text`: signal input for footer text. |
| `UiStateService` | `isSidebarOpen`, `toggleSidebar()`, and `closeSidebar()`. |

## Customize the sidebar

The packaged sidebar currently mirrors the demo navigation labels and icons. For application-specific navigation, copy the component template into the consuming project or wrap the exported state service in a custom standalone sidebar. The shared service remains available:

```typescript
import { Component, inject } from '@angular/core';
import { UiStateService } from '@novan/dashboard-ui';

@Component({
  selector: 'app-custom-sidebar-toggle',
  standalone: true,
  template: `
    <button type="button" (click)="uiState.toggleSidebar()">
      {{ uiState.isSidebarOpen() ? 'Close' : 'Open' }}
    </button>
  `,
})
export class CustomSidebarToggleComponent {
  protected readonly uiState = inject(UiStateService);
}
```

## Skills and feature guidance

The package exposes runtime UI features and components, not editor-agent skills. The reusable feature set currently consists of the dashboard shell, responsive layout styling, Bootstrap integration, icon styling, standalone components, and cookie-backed sidebar state. Project-specific Copilot skills or instruction files are not executable npm dependencies and are intentionally not included in the runtime package.

## Publish the package

Update `projects/novan-dashboard-ui/package.json` with the intended version and registry metadata, then build and publish the generated package directory:

```bash
npm run build:library
cd dist/novan-dashboard-ui
npm publish --access public
```

For a private registry, configure the registry and authentication according to that registry before running `npm publish`.

Before publishing, verify the package contents:

```bash
npm pack --dry-run ./dist/novan-dashboard-ui
```

## Verify changes locally

Run the application build and tests from the repository root:

```bash
npm run build
npx ng test --watch=false
npm run build:library
```

The package build must complete before the generated `dist/novan-dashboard-ui/` directory is installed or published.
